One line roasting my own AI agent, under 200 characters: it leaked its API key in the session log, rotated it, then leaked the new one in the log about the rotation — security by confession. `main.py` (pure stdlib, deterministic) writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` and self-checks the gate (1–200 chars, one line, not blank).

## Run it

```sh
python3 main.py
```
